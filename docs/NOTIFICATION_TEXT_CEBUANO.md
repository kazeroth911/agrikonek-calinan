# Notification wording: Cebuano review sheet

The Cebuano below was written to match words the app already uses (*tanyag* = bid/offer, *baylo* = barter, *Gidawat* = accepted, *Wala gidawat* = rejected, *Gi-counter* = countered, *baligya* = listing, *pahibalo* = notice). It has **not yet been checked by a native speaker**. Please have a Cebuano-speaking team member go through each line before the app is shown to farmers.

For each row, write **OK** or a better phrasing in the last column. Keep each Cebuano title short: phones cut off long push titles.

## Language setting

The app no longer shows English and Cebuano side by side. Each user picks **English** or **Cebuano (Bisaya)**:

- on the sign-in screen, with the language button at the top right;
- in **My profile → Language** (farmers) or the gear icon on the researcher home screen.

The choice is saved on the phone and also sent with the phone's push registration, so phone notifications arrive in the same language. Rows 1 to 19 above are therefore shown in one language at a time, never both.

## Changing a line

Every line lives in two files that must match exactly:

- `functions/notification_text.js` (the phone push)
- `lib/features/notifications/notification_text.dart` (the in-app inbox)

Row 17 lives in `android/app/src/main/kotlin/com/agrikonek/agrikonek_calinan/MainActivity.kt`.

On-screen text lives in the screen's own file, written as `context.tr('English', 'Cebuano')`. Change the Cebuano there; nothing else needs to match.

After editing a notification line, run `npm test` in `functions` (it fails if the two files disagree) and `flutter test` in the project root, then update the expected text in `functions/test/notification_text.test.js` and `test/models/app_notification_test.dart` if those tests name the line you changed.
